# ADR-05: Поиск: FTS + trigram + синонимы

**Статус:** принято · **Дата:** 2026-11-17

## Решение
Postgres FTS (russian+english), pg_trgm, unaccent, search_synonym; без эмбеддингов.

## Обоснование
Объяснимо, отлаживаемо, без внешнего сервиса. pgvector без корпуса и метрик — имитация семантики.

## Последствия
- Обязательно для всех этапов; изменение — только новым ADR.
- Проверяется на код-ревью и в тестах соответствующих модулей.
