# ADR-10: MapLibre GL + OSM

**Статус:** принято · **Дата:** 2026-11-17

## Решение
Карта опциональна; при недоступных тайлах — список зоопарков.

## Обоснование
Нет API-ключа и биллинга; деградация без потери функциональности.

## Последствия
- Обязательно для всех этапов; изменение — только новым ADR.
- Проверяется на код-ревью и в тестах соответствующих модулей.
