# ADR-07: Cookie-сессии + Argon2id, RBAC

**Статус:** принято · **Дата:** 2026-11-17

## Решение
VIEWER/EDITOR/ADMIN; серверные сессии; без JWT в localStorage и без OAuth.

## Обоснование
Сессии отзываемы, cookie httpOnly, тестируются проще; SSO избыточен для курсовой.

## Последствия
- Обязательно для всех этапов; изменение — только новым ADR.
- Проверяется на код-ревью и в тестах соответствующих модулей.
