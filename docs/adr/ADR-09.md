# ADR-09: Без Redis и очередей

**Статус:** принято · **Дата:** 2026-11-17

## Решение
In-memory LRU с TTL, HTTP/Next-кэш; rate limit в памяти; интерфейс CacheStore для расширения.

## Обоснование
Один узел и учебная нагрузка не требуют Redis; лишний компонент усложняет запуск.

## Последствия
- Обязательно для всех этапов; изменение — только новым ADR.
- Проверяется на код-ревью и в тестах соответствующих модулей.
