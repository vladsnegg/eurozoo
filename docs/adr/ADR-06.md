# ADR-06: Граф на клиенте, подграф на сервере

**Статус:** принято · **Дата:** 2026-11-17

## Решение
Сервер отдаёт {nodes,edges} через BFS CTE с whitelist и лимитами; клиент рисует React Flow + ELK.

## Обоснование
Клиент не может строить граф по всем данным; лимиты защищают от взрыва связей.

## Последствия
- Обязательно для всех этапов; изменение — только новым ADR.
- Проверяется на код-ревью и в тестах соответствующих модулей.
