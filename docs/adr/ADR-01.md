# ADR-01: PostgreSQL как единственный источник истины

**Статус:** принято · **Дата:** 2026-11-17

## Решение
Не вводим отдельную графовую БД. Связи хранятся в Postgres: FK + knowledge_edge + рекурсивные CTE.

## Обоснование
Граф — представление связей, а не замена реляционному ядру. Neo4j потребовал бы двойной записи и второй движок без выгоды для курсовой.

## Последствия
- Обязательно для всех этапов; изменение — только новым ADR.
- Проверяется на код-ревью и в тестах соответствующих модулей.
