# ADR-02: Гибридная модель связей

**Статус:** принято · **Дата:** 2026-11-17

## Решение
Структурные связи — FK-колонки; сквозные/мягкие — knowledge_edge с предикатом из реестра.

## Обоснование
Полный EAV теряет целостность; полная нормализация не выражает роли/годы/достоверность для произвольных связей.

## Последствия
- Обязательно для всех этапов; изменение — только новым ADR.
- Проверяется на код-ревью и в тестах соответствующих модулей.
