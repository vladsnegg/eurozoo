# ADR-11: Тестовая БД в Compose

**Статус:** принято · **Дата:** 2026-11-17

## Решение
Отдельная база eurozoo_test, миграции Prisma, truncate между тестами.

## Обоснование
Testcontainers на Windows/Docker Desktop нестабильны; отдельная БД воспроизводима в CI.

## Последствия
- Обязательно для всех этапов; изменение — только новым ADR.
- Проверяется на код-ревью и в тестах соответствующих модулей.
