# ADR-04: Единая таблица taxon с parent_id

**Статус:** принято · **Дата:** 2026-11-17

## Решение
Ранги — справочник, а не таблицы family/order/species.

## Обоснование
Смена классификации не требует миграции; глубина произвольная; нет дублирования структуры.

## Последствия
- Обязательно для всех этапов; изменение — только новым ADR.
- Проверяется на код-ревью и в тестах соответствующих модулей.
