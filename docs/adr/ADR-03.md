# ADR-03: Онтология как реестр предикатов

**Статус:** принято · **Дата:** 2026-11-17

## Решение
predicate + taxonomic_rank + enum-справочники; OWL/RDF не внедряем, TTL-экспорт — опция P2.

## Обоснование
Нет потребителя OWL в UI/API; реестр валидируется приложением и достаточен для поиска/графа.

## Последствия
- Обязательно для всех этапов; изменение — только новым ADR.
- Проверяется на код-ревью и в тестах соответствующих модулей.
