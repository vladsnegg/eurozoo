# ADR-12: Данные только из источников

**Статус:** принято · **Дата:** 2026-11-17

## Решение
published требует entity_source с verified_at; null = неизвестно.

## Обоснование
Требование достоверности; исключает выдуманные факты и «примерные» значения.

## Последствия
- Обязательно для всех этапов; изменение — только новым ADR.
- Проверяется на код-ревью и в тестах соответствующих модулей.
