# ADR-08: Монорепо pnpm + Turborepo

**Статус:** принято · **Дата:** 2026-11-17

## Решение
apps/web (Next.js 15), apps/api (NestJS 11), packages/shared (zod).

## Обоснование
Единые типы контрактов, кэш сборки, совместимо с прежним стеком.

## Последствия
- Обязательно для всех этапов; изменение — только новым ADR.
- Проверяется на код-ревью и в тестах соответствующих модулей.
