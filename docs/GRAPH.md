# Граф знаний

## API

`GET /api/v1/graph?seed=<type>:<uuid>&depth=1..3&types=a,b&predicates=CODE1,CODE2&inferred=true&limit=1..200`

- `seed` — стартовая сущность: `zoo`, `species`, `taxon`, `country`, `city`, `program`, `organization`, `research`.
- `depth` — 1–3 (по умолчанию 1).
- `types` — фильтр типов узлов (после обхода).
- `predicates` — фильтр связей; неизвестный код → `400`.
- `inferred` — включать выведенные связи (R3); по умолчанию `false`.
- `limit` — максимум узлов, 1–200.

Ответ: `{nodes, edges, truncated, stats}`. `truncated=true`, если связей больше 400 или узлов больше лимита.

`GET /api/v1/graph/predicates` — список реально встречающихся предикатов с русскими подписями (для UI).

## Модель обхода

- Единое представление `v_all_edges` объединяет структурные связи (FK), `knowledge_edge` и выведенные связи R3.
- Рекурсивный CTE обходит рёбра в обоих направлениях, глубина ограничена 3, защита от циклов — `UNION` + лимит глубины.
- Фильтр `published`: в граф не попадают draft-сущности; программы/организации/исследования — только опубликованные.
- Узлы подписываются через сервис проекции; для типов без поддержки узел не выводится.
- Степень узла = число уникальных рёбер, попавших в ответ.

## Ограничения

- Максимум 200 узлов / 400 рёбер за ответ; UI предупреждает о truncation.
- Фильтр типов применяется к узлам, но не прерывает обход (иначе теряются промежуточные таксоны).
- `knowledge_edge` в сиде пуст; сквозные связи появятся на этапе 8.

## UI

`/graph?seed=type:id&depth=2` — React Flow + ELK, фильтры, панель узла, список связей, экспорт PNG, копирование ссылки, восстановление состояния из URL.
