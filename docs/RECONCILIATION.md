## 2. Обоснование bootstrap-коммита в `main`

Master prompt запрещает пушить в `main`. Для пустого репозитория это правило неприменимо к первичной инициализации: без базовой ветки невозможно ни создать `stage/*`, ни открыть PR. Поэтому:

- в `main` попадает **только** `README.md` и `.gitignore`;
- никакого кода, конфигов и секретов;
- все дальнейшие изменения — через `stage/NN-*` и PR;
- факт зафиксирован в `docs/AUDIT.md` §10 и здесь.

## 3. Что сохраняется из прежней локальной копии

Ничего: копия удалена по распоряжению владельца, а её содержимое не задокументировано. Перенос кода невозможен и не требуется; совместимость обеспечена выбором стека (Next.js/NestJS/Prisma/PostgreSQL) и контрактами API из спецификации.
