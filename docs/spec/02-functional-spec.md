# ЧАСТЬ III. Функциональная спецификация

Каждый модуль описан как: назначение → пользовательские истории → поведение → критерии приёмки. Требования к тестам — в `06-delivery-plan.md`.

## A. Главная страница и навигация

**Назначение:** за 5 секунд объяснить, что это база знаний, и дать 3 пути входа: каталог, поиск, граф.

**Содержимое (сверху вниз):**
1. Заголовок + подзаголовок + строка поиска (тот же компонент, что в хедере; запрос уходит на `/search?q=`).
2. Четыре счётчика из API `/stats`: зоопарков, видов, стран, программ. Числа реальные, не захардкоженные.
3. «Начните отсюда»: 6 карточек-категорий (Зоопарки, Виды, География, Программы, Организации, Граф знаний) с иконкой, коротким описанием и ссылкой.
4. «Недавно обновлено» — 8 последних `published` сущностей по `updated_at`, с типом и датой.
5. «Популярные связи» — 5 рёбер с наибольшим числом связей (например, виды с максимумом зоопарков). Данные из `/stats/highlights`.
6. Футер: версия, ссылка на «Источники и методику», GitHub.

**Правила:**
- Никаких каруселей, видео, анимаций входа.
- Если данных нет — empty state с инструкцией запустить сид, не «coming soon».
- Время ответа главной ≤ 300 мс при сиде (один SQL-запрос на каждый блок, без N+1).

**Критерии приёмки:** все цифры совпадают с `/stats`; каждый блок имеет ссылку; LCP < 2.5 с на локальном прод-билде; страница работает при отключённом JS (SSR-контент виден).

## B. Зоопарки

**Каталог `/zoos`:**
- Таблица/сетка (переключатель не нужен: карточки на десктопе 3 в ряд, на мобильном 1).
- Поля карточки: название, локальное название, город/страна, год основания, число видов (из `zoo_species`), бейдж участия в программах, координаты → ссылка на карту.
- Фильтры (sidebar, синхронизированы с URL): страна (multi), город, год основания (диапазон), «участвует в программах» (bool), «есть виды под угрозой» (bool, вычисляется), наличие координат.
- Сортировка: по названию, по году основания, по числу видов, по дате обновления.
- Пагинация: offset, `pageSize=24`, максимум 100.
- Пустое состояние: «Ничего не найдено. Сбросить фильтры».

**Карточка `/zoos/[slug]`:**
- Хедер: название, локальное название, страна/город, статус (`active/closed`), год основания, площадь, посетители/год, сайт (внешняя ссылка с `rel="noopener noreferrer"`).
- Вкладки/секции: Обзор (описание), Виды (таблица: вид, охранный статус, кол-во, разведение), Программы (роль, годы), Организации, Исследования, Образование, Инфраструктура, История (таймлайн), Источники.
- Каждая секция — свой запрос с `include`; данные не грузятся целиком одной «простынёй».
- Для каждого факта — иконка источника (тултип: источник, дата проверки, достоверность) и бейдж `inferred`, если факт выведен.
- «Похожие зоопарки» — 4 карточки по Jaccard-сходству.
- 404 при неизвестном slug (кастомная страница, не пустой экран).

**Критерии приёмки:** фильтры комбинируются (AND между группами, OR внутри группы); при смене фильтра URL меняется и состояние восстанавливается при перезагрузке; карточка не делает > 6 параллельных запросов; все внешние ссылки безопасны; отсутствие данных отображается как «нет данных», а не `0`.

## C. Животные и биологическая классификация

**Каталог `/species`:** карточки (научное имя курсивом, русское/английское имя, IUCN-бейдж с цветом, число зоопарков). Фильтры: IUCN-статус (multi), класс/отряд/семейство (выбор из дерева таксонов), биом/ареал, «содержится в N странах», «участвует в программах».

**Карточка `/species/[slug]`:**
- Хедер: научное имя, автор/год описания, русское и английское названия, IUCN-статус (цвет + расшифровка), тренд популяции.
- Таксономическая линия (breadcrumb-дерево kingdom→…→species) — кликабельно вверх; список дочерних таксонов внизу.
- Профиль: ареалы (habitat-чипы), продолжительность жизни, масса/длина (диапазоны), особенности содержания, описание.
- «Где содержится» — зоопарки (таблица с городом/страной, количеством, разведением, годом).
- «Программы» — программы, нацеленные на вид, и зоопарки-участники (включая inferred «зоопарк участвует в программе по виду»).
- «Исследования» — проекты, изучающие вид.
- Источники.

**Критерии приёмки:** линия таксонов всегда доходит до корня; если у вида нет профиля — страница не падает (показывает «профиль не заполнен»); IUCN-цвет соответствует severity; фильтр по семейству возвращает все виды-потомки, не только прямых детей.

## D. Географический раздел

**`/countries`:** список стран с числом зоопарков и видов (агрегаты), флаг (эмодзи или SVG по ISO), ISO-код.
**`/countries/[slug]`:** карточка страны: ISO, столица (если хранится), регионы, города, зоопарки, организации, сводка по IUCN.
**`/cities/[slug]`:** город, регион, страна, координаты, список зоопарков, карта.
**`/map`:** MapLibre, кластеризация зоопарков, попап с названием и ссылкой, фильтр по стране. Если тайлы недоступны — сообщение и список зоопарков вместо карты.

**Критерии приёмки:** агрегаты совпадают с каталогом (проверка тестом на фикстурах); карта не блокирует рендер (lazy import); кластеризация работает при 30+ точках; при `prefers-reduced-motion` анимации отключены.

## E. Природоохранная деятельность

**`/programs`:** каталог программ (код EEP/ESB/STUDBOOK/OTHER, название, организация-оператор, годы, число целевых видов, число зоопарков). Фильтры: код, организация, страна, «активна/завершена».
**`/programs/[slug]`:** описание, оператор, период, целевые виды (карточки), зоопарки-участники с ролями и годами, связанные исследования, источники.
**`/organizations` и `/organizations/[slug]`:** тип, страна, годы, сайт, зоопарки-члены, программы, исследования.

**Критерии приёмки:** программа без целевых видов не может быть опубликована; роль участника (координатор/участник/бывший) отображается; «бывший участник» не входит в счётчик активных.

## F. Поиск и исследование знаний

**Глобальный поиск (хедер + `/search`):**
- Один инпут, debounce 300 мс, запросы отменяются при новом вводе (`AbortController`).
- Результаты сгруппированы по типу (Зоопарки, Виды, Страны, Программы, Организации), внутри — релевантность.
- Каждый результат: заголовок с подсветкой совпадений, подзаголовок (контекст: город/страна, IUCN, код программы), бейдж типа, ссылка на карточку.
- Фасеты слева: тип сущности, страна, IUCN, код программы. Фасеты приходят с сервера вместе с результатами (`/search/facets` или в ответе).
- Пагинация: `page`, `pageSize=20`.
- Пустой результат: «По запросу ничего не найдено» + 5 нечётких подсказок (trigram) + ссылка на расширенный поиск.
- Поиск по синонимам: словарь `search_synonym` (например, «панда» → «большая панда», «Ailuropoda melanoleuca»; «кипер» → «сотрудник»). Словарь управляется администратором.
- Явная маркировка: «Поиск по знаниям» (FTS + онтология), не «AI-поиск».

**Страницы «связанного»:**
- «Похожие объекты» на каждой карточке: для зоопарков — по видам/программам, для видов — по таксономии и зоопаркам, для программ — по видам и организациям.
- «Переходы знаний»: блок «Связано с» — 5–8 рёбер, сгруппированных по предикату, с типом связи и переходом.

**Где НЕ нужен семантический поиск:** точные справочные выборки (список зоопарков страны) — только фильтры; поиск по коду ISO/EEP — точное совпадение; админ-таблицы — серверная фильтрация по колонкам.

**Критерии приёмки:** запрос «тигр» находит вид и зоопарки, где он содержится (через связи, не только по названию); p95 ≤ 400 мс на сиде; 0 результатов не приводит к 500; подсветка экранирует HTML; фасеты не ломаются при пустом результате.

## G. Визуализация связей

**`/graph`:** полноэкранная сцена + панель управления.
- Стартовые узлы: выбор сущности (autocomplete) или переход с карточки кнопкой «Открыть в графе».
- Параметры: глубина 1–3, типы узлов (чекбоксы), предикаты (чекбоксы из реестра), «показывать выведенные» (bool), лимит узлов (≤ 200).
- Узлы: цвет по типу, размер по степени, подпись (название, сокращается), клик → боковая панель с кратким описанием и ссылкой «Открыть карточку».
- Рёбра: подпись предиката на hover, dashed для `inferred`, толщина по confidence.
- Кнопки: «Развернуть узел» (добавляет соседей), «Сбросить», «Экспорт PNG» (клиентский), «Скопировать ссылку» (URL с seed/depth/фильтрами).
- Ограничения: сервер отдаёт ≤ 200 узлов и ≤ 400 рёбер; при превышении — предупреждение «показаны не все связи, уменьшите глубину».

**Критерии приёмки:** нет дублей узлов; циклы не вызывают бесконечную загрузку; при depth=1 граф совпадает с блоком «Связано с» на карточке; URL восстанавливает состояние; на мобильном граф работает (панорамирование/зум), панель управления сворачивается.

## H. Административная панель

**`/admin` (защищено ролью):** дашборд — счётчики, сущности без источников, стейл-факты, последние изменения, ошибки валидации.
**CRUD для:** zoos, species/taxa, countries/cities/regions, programs, organizations, research, education, facilities, events, sources, synonyms, users.
- Список: серверная пагинация, поиск по колонкам, сортировка, фильтр статуса.
- Форма: zod-валидация на клиенте и сервере, подсказки, inline-ошибки, «грязный» guard при уходе, `updated_at` для оптимистической блокировки (409 при конфликте).
- Связи: редактор M:N (поиск + добавление + удаление), для `zoo_species` — количества и годы, для `knowledge_edge` — предикат из реестра с проверкой домена/диапазона.
- Публикация: `draft → review → published`; публикация блокируется без источника; кнопка «Проверено» ставит `verified_at`.
- Источники: добавление/редактирование, привязка к сущности/полю, confidence 0–100, статус current/stale/disputed.
- Пользователи: список, смена роли, деактивация; нельзя деактивировать последнего администратора.
- Журнал: `knowledge_revision` — кто, что, когда, diff.

**Критерии приёмки:** VIEWER не видит `/admin` (403), EDITOR не управляет пользователями (403), ADMIN всё; удаление сущности с зависимостями возвращает 409 с перечнем; каждая мутация пишет ревизию; формы не теряют данные при ошибке сервера.

## I. Источники и достоверность

- У каждой публикуемой сущности ≥1 источник.
- `source`: тип (official_site, scientific, database, media, community), название, URL, издатель, дата публикации, дата доступа, лицензия, надёжность.
- `entity_source`: сущность + источник + опционально поле + confidence (0–1) + retrieved_at + verified_at + status.
- UI: бейдж источника на факте, страница `/sources` со списком и статистикой, страница `/about/methodology` с объяснением методики.
- Стейл: `stale_after` (по умолчанию +12 месяцев); задача `pnpm data:stale` выводит отчёт; UI показывает «данные устарели».
- Запрет выдуманных фактов: сервис отклоняет `published` без источника; сид-данные проверяются скриптом (`data:verify`) против списка допустимых доменов и наличия URL.

**Критерии приёмки:** попытка опубликовать без источника → 422 с понятным сообщением; на карточке видно дату проверки; удаление источника, на который ссылаются, запрещено (409).

## J. Пользователи и безопасность

Роли и права:

| Действие | VIEWER (гость) | EDITOR | ADMIN |
|---|---|---|---|
| Чтение всех published | ✅ | ✅ | ✅ |
| Чтение draft | ❌ | ✅ | ✅ |
| Создание/редактирование контента | ❌ | ✅ | ✅ |
| Публикация | ❌ | ✅ (после review) | ✅ |
| Удаление сущностей | ❌ | ❌ | ✅ |
| Источники, синонимы | ❌ | ✅ | ✅ |
| Пользователи, роли | ❌ | ❌ | ✅ |
| Журнал ревизий | ❌ | ✅ | ✅ |

Требования безопасности: Argon2id (memory 19 MiB, iterations 2, parallelism 1 — baseline OWASP); пароль ≥ 12 символов; сессия 7 дней, sliding, httpOnly, Secure (prod), SameSite=Lax; CSRF — проверка `Origin` для не-GET; rate limit логина 5/мин/IP и 10/час/аккаунт; блокировка после 10 неудач на 15 мин; все входные данные через zod; SQL — только Prisma/параметризованные запросы; заголовки: CSP (без `unsafe-inline` в prod), `X-Content-Type-Options`, `Referrer-Policy`; логи без паролей/токенов; ошибки наружу — без стектрейсов (в dev — можно).

**Критерии приёмки:** OWASP-чеклист пройден по пунктам, применимым к системе (A01, A02, A03, A05, A07, A08, A09); интеграционные тесты доказывают 401/403 для каждого защищённого маршрута; секретов в репозитории нет (`git grep` + secret-scan в CI).

## API v1 (контракт, сводно)

База: `/api/v1`. Формат: JSON; ошибки — RFC 7807 (`type`, `title`, `status`, `detail`, `instance`, `errors[]`).

| Метод/путь | Назначение |
|---|---|
| `GET /health` | liveness/readiness (db ping, версия) |
| `GET /stats` | счётчики + highlights |
| `GET /zoos`, `GET /zoos/:slug` | каталог/карточка (include=species,programs,orgs,research,events,facilities,sources) |
| `GET /species`, `GET /species/:slug` | виды + таксономия + программы + зоопарки |
| `GET /taxa`, `GET /taxa/:id/children`, `GET /taxa/:id/lineage` | дерево, потомки ранга |
| `GET /countries`, `GET /countries/:slug` | страны + агрегаты |
| `GET /cities/:slug` | город + зоопарки |
| `GET /programs`, `GET /programs/:slug` | программы |
| `GET /organizations`, `GET /organizations/:slug` | организации |
| `GET /research`, `GET /research/:slug` | исследования |
| `GET /search?q&types&facets` | поиск + фасеты + suggestions |
| `GET /graph?seed=type:id&depth&types&predicates&inferred&limit` | подграф |
| `GET /entities/:type/:id/related?limit=8` | «связано с» |
| `GET /entities/:type/:id/similar?limit=4` | похожие |
| `POST /auth/login`, `POST /auth/logout`, `GET /auth/me` | сессии |
| `/admin/*` | CRUD, публикация, источники, синонимы, пользователи, ревизии |

Правила API: `page`/`pageSize` (1..100), `sort` — whitelist колонок, `include` — whitelist, неизвестный параметр → 400, `ETag` на карточках, `Cache-Control: public, max-age=60, stale-while-revalidate=300` для чтения, `no-store` для админки.
