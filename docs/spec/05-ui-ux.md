# ЧАСТЬ VII. Проектирование интерфейса

## VII.1. Принципы

1. **Знания важнее декора.** Нет анимаций, каруселей, «красивых» графиков ради графиков. Каждый элемент либо несёт информацию, либо помогает навигации.
2. **Один путь к любому объекту.** Любая сущность достижима за ≤ 2 клика от карточки, где она упомянута.
3. **Провенанс виден.** Источник — не «где-то в подвале», а бейдж рядом с фактом.
4. **Явная неопределённость.** «Нет данных» ≠ 0; «выведено» ≠ факт.
5. **Доступность.** Контраст ≥ 4.5:1, фокус-кольца, клавиатурная навигация, `prefers-reduced-motion`.

## VII.5. Компоненты (обязательный минимум)

| Компонент | Назначение | Требования |
|---|---|---|
| `Header` | навигация + глобальный поиск | sticky, мобильное меню, активный раздел |
| `SearchInput` | поиск с debounce | `role="searchbox"`, отмена запросов, лоадер |
| `EntityCard` | карточка объекта | тип, заголовок, контекст, бейджи, стрелка |
| `DataTable` | таблицы (виды, админ) | сортировка, пагинация, пустое состояние, `caption` |
| `FilterPanel` | фасеты | URL-синхронизация, счётчики, сброс |
| `SourceBadge` | провенанс | тултип: источник, дата, достоверность |
| `IucnBadge` | статус IUCN | цвет + текст (не только цвет) |
| `LineageTree` | таксономия | клавиатура, раскрытие, ссылки |
| `GraphCanvas` | граф | зум/пан, мини-легенда, лимит узлов |
| `EmptyState` | пусто | текст + действие |
| `Skeleton` | загрузка | фиксированные размеры, без layout shift |
| `ErrorState` | ошибка | код, сообщение, «Повторить» |
| `FormField` | формы | label, hint, error, `aria-describedby` |

## VII.6. Адаптивность

- Брейкпоинты: 380, 640, 900, 1200.
- Каталог: 3 → 2 → 1 колонка; фильтры на мобильном — выдвижная панель.
- Таблицы: горизонтальный скролл с тенью-подсказкой; на мобильном ключевые колонки «закрепляются» (название).
- Граф: панель управления в шторке, canvas занимает весь экран.
- Меню: burger → полноэкранное меню, поиск первым пунктом.

## VII.7. Состояния и обратная связь

- Загрузка: скелеты 200–600 мс; если > 600 мс — «Загружаем…» без спиннеров-каруселей.
- Пусто: текст + действие («Сбросить фильтры», «Добавить источник»).
- Ошибка: код + человеческое сообщение + «Повторить» + `requestId` для поддержки.
- Успех: toast 3 с («Сохранено», «Опубликовано»), без модальных «успехов».
- Несохранённые изменения: `beforeunload` + диалог.

## VII.8. SEO и метаданные

- `<title>`: «{Название} — EuroZoo Atlas»; description из описания (≤ 160 символов).
- Open Graph: заголовок, описание, тип; изображения — только если реально есть.
- Canonical для карточек; `sitemap.xml` генерируется из published-сущностей; `robots.txt` закрывает `/admin`.
- Структурированные данные (`JSON-LD`): `Organization` для зоопарка, `Taxon`-подобное описание — по возможности, без ложных полей.
