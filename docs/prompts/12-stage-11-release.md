2. Compose: `docker-compose.prod.yml` — без публикации БД, только внутренняя сеть, volume для данных и uploads.
3. Производительность: профилировать 5 самых тяжёлых запросов; устранить N+1; проверить индексы; включить кэш чтения; замерить p95 до/после.
4. Документация: `README.md` (обзор, стек, быстрый старт, команды, структура, troubleshooting), `docs/DEMO.md` (сценарий 7 минут с точными шагами и ожидаемым результатом), `docs/CHANGELOG.md`, `docs/ARCHITECTURE.md` актуализирован, `docs/DATA-REPORT.md`, `docs/QA-REPORT.md`.
5. Бэкап/восстановление: `pg_dump`/`pg_restore` инструкции, скрипт `scripts/backup.sh`/`.ps1`, проверка восстановления на чистой БД.
6. Демо-данные: фиксированный набор (сид), сценарий не зависит от интернета, кроме карты (fallback).
7. Тег `v1.0.0`, релизные заметки.
